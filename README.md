# Study Planner Web App

A responsive and modern Study Planner web application built using React, Tailwind CSS, and Framer Motion.

## Features

- Add and delete tasks
- Mark tasks as completed
- Persistent task saving using Local Storage
- Responsive design for mobile and desktop
- Smooth UI animations
- Modern dashboard interface

## Tech Stack

- React
- Tailwind CSS
- Framer Motion
- Vite

## Live Demo

https://study-planner-seven-sand.vercel.app/

## Installation

```bash
npm install
npm run dev
```
